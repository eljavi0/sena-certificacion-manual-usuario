# Manual de Usuario — SENA Certificación App

## Contenido
- `index.html` — Manual completo (navegación lateral + todas las secciones)
- `style.css` — Estilos con la paleta de la aplicación
- `img/` — **Créela usted** y coloque las capturas numeradas

## Cómo usar
1. Cree la carpeta `img/` dentro de esta misma carpeta.
2. Tome las capturas de pantalla de la app y guárdelas con estos nombres exactos:

| Archivo | Qué capturar |
|---------|----------------|
| `img/captura01.png` | Barra lateral (rail) de navegación |
| `img/captura02.png` | Vista «Cargar información» |
| `img/captura03.png` | Tipo de fuente + zona de carga |
| `img/captura04.png` | Vista previa de importación |
| `img/captura05.png` | Importación exitosa |
| `img/captura06.png` | Advertencias / conflictos en vista previa |
| `img/captura07.png` | Panel de resolución de conflictos |
| `img/captura08.png` | Panel Google Sheets |
| `img/captura09.png` | Estado de sincronización Sheets |
| `img/captura10.png` | Listado de aprendices |
| `img/captura11.png` | Filtros y chips de estado |
| `img/captura12.png` | Detalle de un aprendiz |
| `img/captura13.png` | Requisitos del aprendiz |
| `img/captura14.png` | Listado de actas |
| `img/captura15.png` | Detalle de acta + aprendices |
| `img/captura16.png` | Vista de indicadores |

3. Abra `index.html` en el navegador (doble clic o servidor local).

Si una imagen aún no existe, se muestra un espacio reservado con el nombre del archivo esperado.

## Nota
La sección **Informe de gestión** no está incluida todavía; se agregará cuando esa funcionalidad esté completa.

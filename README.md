# Manual de Usuario — SENA Certificación App

## Contenido
- `index.html` — Manual completo (navegación lateral + todas las secciones F1–F10)
- `style.css` — Estilos con la paleta de la aplicación
- `img/` — **Créela usted** y coloque las capturas numeradas

## Cómo usar
1. Cree la carpeta `img/` dentro de esta misma carpeta.
2. Tome las capturas de pantalla de la app y guárdelas con estos nombres exactos:

| Archivo | Qué capturar | Sección |
|---------|----------------|---------|
| `img/captura01.png` | Barra lateral (rail) de navegación | F1 |
| `img/captura02.png` | Vista «Cargar información» | F2 |
| `img/captura03.png` | Tipo de fuente + zona de carga | F2 |
| `img/captura04.png` | Vista previa de importación | F3 |
| `img/captura05.png` | Importación exitosa | F3 |
| `img/captura06.png` | Advertencias / conflictos en vista previa | F3/F4 |
| `img/captura07.png` | Panel de resolución de conflictos | F4 |
| `img/captura08.png` | Panel Google Sheets | F5 |
| `img/captura09.png` | Estado de sincronización Sheets | F5 |
| `img/captura10.png` | Listado de aprendices | F6 |
| `img/captura11.png` | Filtros y chips de estado | F6 |
| `img/captura12.png` | Detalle de un aprendiz | F7 |
| `img/captura13.png` | Requisitos del aprendiz | F7 |
| `img/captura14.png` | Listado de actas | F8 |
| `img/captura15.png` | Detalle de acta + aprendices | F8 |
| `img/captura16.png` | Vista de indicadores | F9 |
| `img/captura17.png` | Informe de gestión: año/trimestre y pestañas | F10 |
| `img/captura18.png` | Pestaña Estrategias / actividades | F10 |
| `img/captura19.png` | Pestaña Anexos | F10 |
| `img/captura20.png` | Pestaña Exportar (Generar DOCX) | F10 |

3. Abra `index.html` en el navegador (doble clic o servidor local).

Si una imagen aún no existe, se muestra un espacio reservado con el nombre del archivo esperado.

## Funcionalidades documentadas
F1 Interfaz · F2 Carga · F3 Vista previa · F4 Conflictos · F5 Google Sheets · F6 Aprendices · F7 Detalle aprendiz · F8 Actas · F9 Indicadores · **F10 Informe de gestión administrativa**
